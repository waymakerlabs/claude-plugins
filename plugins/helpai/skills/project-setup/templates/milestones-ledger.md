# 마일스톤 원장

모든 마일스톤 플랜과 현재 진행 위치를 한눈에 보는 문서입니다. 플랜 폴더 안의 문서가 상세 내용의 진본이고, 이 원장은 요약입니다.

## 플랜 목록

| 플랜 | 이름 | 상태 | 진행 위치 | 시작 | 종료 |
| --- | --- | --- | --- | --- | --- |

## ID 규칙

- 형식은 `M{플랜번호}-{순번}`입니다. 예: `M1-01`, `M1-02`, `M2-01`.
- 새 마일스톤 플랜을 세울 때마다 플랜 번호를 1 올리고, 순번은 플랜마다 `01`부터 다시 시작합니다.
- 플랜을 세울 때 그 플랜의 마일스톤 전체를 `planned`로 먼저 등재합니다. 그래야 "03/05" 같은 진행 위치를 계산할 수 있습니다.
- 도중에 마일스톤이 추가되면 맨 뒤 번호를 새로 부여합니다. 이미 부여한 번호는 바꾸거나 재사용하지 않습니다. `M1-02a` 같은 끼워 넣기 번호는 쓰지 않습니다.
- 상태 값은 `planned` / `in-progress` / `blocked` / `done` / `dropped`만 씁니다.

## 폴더 구조

```
docs/milestones/
├── README.md                  # 이 원장
└── M1-<플랜-slug>/
    ├── README.md              # 플랜 개요
    └── M1-01-<slug>/
        ├── plan.md            # 시작할 때 작성
        ├── progress.md        # 진행하면서 아래에 이어 씀
        └── result.md          # 종료할 때 작성
```

## 문서 형식

### 플랜 개요 (`M{n}-<slug>/README.md`)

```markdown
# M{n} <플랜 이름>

- 목표: <이 플랜이 끝나면 무엇이 달라지는가, 1~2문장>
- 종료 조건: <플랜 전체가 끝났다고 판단하는 기준>

| 마일스톤 | 이름 | 상태 | 시작 | 종료 |
| --- | --- | --- | --- | --- |
| M{n}-01 | [<이름>](M{n}-01-<slug>/plan.md) | planned | | |
```

### 마일스톤 계획 (`plan.md`)

```markdown
# M{n}-{nn} <이름>

- 목표:
- 범위 / 범위 밖:
- 종료 조건: <검증 가능한 문장으로>

## Task
- [ ] T1 <할 일>
```

### 진행 기록 (`progress.md`, 아래에 이어 쓰기만 합니다)

```markdown
## YYYY-MM-DD
- 한 일:
- 검증: <실행한 명령과 결과>
- 다음 착수 지점:
```

### 결과 (`result.md`)

```markdown
# M{n}-{nn} 결과

- 종료 조건 충족 여부: <조건별로 근거와 함께>
- 검증 증거:
- 남은 이슈 / 후속 마일스톤:
```
