# docs 고정 폴더 세트 (진본)

`project-setup` 스킬은 이 파일만 보고 docs 폴더 구성과 `docs/index.md` 섹션 순서를 정한다.
폴더를 추가할 때는 **이 표에 한 줄을 추가하고 플러그인 버전을 올리면 된다.** 스킬을 다시 실행하면
기존 프로젝트에도 빠진 폴더와 index 섹션이 추가된다(기존 파일은 옮기지 않는다).

| 순서 | 폴더 | index 섹션 제목 | 용도 | 이런 문서를 둔다 |
|---|---|---|---|---|
| 1 | `product/` | 제품 | 제품 정의, 요구사항, 원칙 | 제품 브리프, PRD, 사용자 여정, 품질 기준 |
| 2 | `architecture/` | 아키텍처 | 구조, 설계, 결정 기록 | 시스템 구성도, 모듈 설명, ADR(`architecture/adr/`) |
| 3 | `design/` | 디자인 | UI·디자인 시스템 | 디자인 방향, 토큰, 화면 설계, 목업 |
| 4 | `plans/` | 계획 | 로드맵, 여러 플랜에 걸친 계획 | 로드맵, 분기 계획, 플랜 간 의존 관계 |
| 5 | `milestones/` | 마일스톤 | 플랜별 마일스톤 계획·진행 기록·결과 | `milestones/README.md` 원장과 플랜 폴더 |
| 6 | `operations/` | 운영 | 배포·운영 절차 | 배포 절차, 런북, 환경 설정 설명, 장애 대응 |
| 7 | `archive/` | 보관 | 역사적 baseline, 폐기 문서 | 대체된 계획, 초기 탐색 기록 |

## 배치 규칙

- 고정 폴더 아래 하위 폴더는 자유롭게 만든다(예: `architecture/adr/`, `design/mockups/`).
- `docs/` 바로 아래에는 `index.md` 외의 문서를 두지 않는 것을 원칙으로 한다.
- 고정 세트에 맞지 않는 기존 폴더는 옮기지 않는다. index의 「기타」 섹션에 등재한다.
- 폐기 문서는 삭제하지 않고 `archive/`로 옮긴 뒤 상태를 `historical`로 바꾼다.

## index 상태 값 (enum, 이 3개만 사용)

| 값 | 의미 |
|---|---|
| `current` | 지금 기준이 되는 문서 |
| `draft` | 작성 중이거나 아직 합의되지 않은 문서 |
| `historical` | 대체됐거나 기록용으로만 남긴 문서 |

## 마일스톤 상태 값 (enum, 이 5개만 사용)

`planned` · `in-progress` · `blocked` · `done` · `dropped`
